# Social App

A web-based social networking application developed with PHP and MySQL.

## 📌 About the Project

Social App is a web application that allows users to create an account, connect with other users, manage friendships, send friend requests, receive notifications, and interact with the application through a MySQL database.

This project was developed as a practical project to improve my skills in PHP, MySQL, web development, database management, and application architecture.

## ✨ Features

- User registration
- User login and authentication
- User management
- Friend management
- Sending friend requests
- Managing friend requests
- Friend suggestions
- Notifications
- Image/file uploads
- MySQL database integration
